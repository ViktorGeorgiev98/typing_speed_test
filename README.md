# typing_speed_test
A GUI desktop application with python to test how fast you can type

## Details
The test checks how many words you can write per minute (60 seconds). After the timer runs out you will see a message showing how much words you typed and the percentage of correct writing.
At that point, the timer will be reset and you can start writing again whenever you like.

## How it can be started
In the dist folder of the project there is a .exe file called main.exe. You can put this on the PC and start it.
